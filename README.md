# SDGRS XAI lib/cli

## Quickstart

1. [install poetry](https://python-poetry.org/docs/#installing-with-the-official-installer), set python to `3.12` (e.g. via conda or pyenv)
2. `git clone` this repo
3. `poetry install --with dev`
4. open the [XAI notebook in handout](./handout/02-xai-scibert.ipynb) for an example of use via CLI and as a python package.
